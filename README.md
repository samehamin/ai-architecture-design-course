# AI Architecture Design Course
A hands-on course on designing AI systems, aimed at AI/ML and software engineers.


## In a Nutshell
- **Foundations:** general software architecture design and its steps (for any project, not only AI)
- **AI architectures:** LLM, RAG and agent-based system design
- **Production concerns:** security, governance and evaluation
- **Practice:** enterprise case studies and a full Software Design Document (SDD)
